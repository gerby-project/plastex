# plastex (Gerby fork)

This is a fork of plasTeX, to be used for large online mathematical texts
with stable cross-referencing. Documentation is available at the
[Gerby project page](https://gerby-project.github.io).

Gerby supports optional [build-time math and diagram rendering](Doc/gerby-math-rendering.md),
including comparable XyJax v4 and native Xy-pic SVG backends.

plasTeX is a LaTeX compiler written in Python.
Read more at the github page for the plasTeX project:
http://plastex.github.io/plastex/
